# Product Specification

## Boot Flow

Start MediaDeck
→ Select Profile
→ Home
→ Launch YouTube

## Home

- YouTube
- Settings
- Updates

## Profile System

Each profile owns:
- Firefox profile
- YouTube login
- Cookies
- Bookmarks
- Browser preferences
- Future add-ons

## Browser

- Firefox only
- Kiosk mode
- Persistent profile
- Crash recovery
- Automatic image updates
- Hardware acceleration when available

## Responsibilities

MediaDeck:
- Profiles
- Launching Firefox
- Settings
- Updates
- Controller configuration

YouTube:
- Search
- History
- Recommendations
- Playlists
- Subscriptions
- Watch Later
